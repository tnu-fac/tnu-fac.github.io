مكونات نظام الحاسوب
1. مكونات نظام الحاسوب
🏗️ معمارية فون نيومان (Von-Neumann Architecture)

يتكون نظام الحاسوب من المكونات المنطقية التالية:

  • وحدة الإدخال (Input Unit) – الحصول على البيانات من أجهزة الإدخال (لوحة المفاتيح، الفأرة، الماسح الضوئي، ...).
  • وحدة الإخراج (Output Unit) – عرض المعلومات على أجهزة الإخراج (الشاشة، الطابعة، ...).
  • وحدة المعالجة المركزية (CPU) – تنسيق عمل الأقسام الأخرى.
  • وحدة الحساب والمنطق (ALU) – إجراء العمليات الحسابية والعلائقية والمنطقية.
  • وحدة التحكم (Control Unit) – توليد إشارات التحكم لتنفيذ التعليمات.
  • الذاكرة الرئيسية (Main Memory) – تخزين قصير المدى للبيانات والبرامج (RAM).
  • الذاكرة الثانوية (Secondary Storage) – تخزين دائم طويل المدى.

2. لغات البرمجة
الجيل الأول – لغة الآلة (Machine Language)
  • اللغة الوحيدة التي يفهمها الحاسوب مباشرة.
  • تعتمد على الحاسوب (Machine Dependent) .
  • تتكون من رموز ثنائية للبيانات والتعليمات.
0010 0000 0000 0100 0100 0000 0000 0101 0011 0000 0000 0110
الجيل الثاني – لغة التجميع (Assembly Language)
  • تستخدم اختصارات شبيهة باللغة الإنجليزية.
  • تعتمد على الحاسوب (Machine Dependent) .
  • تحتاج إلى مترجم تجميع (Assembler) لتحويلها إلى لغة الآلة.
LOAD BASEPAY
ADD OVERPAY
STORE GROSSPAY
الجيل الثالث – لغات عالية المستوى (Compiler Languages)
  • شبيهة باللغة الإنجليزية، مستقلة عن الحاسوب (Machine Independent) .
  • كل تعليمة في اللغة عالية المستوى تُترجم إلى عدة تعليمات في لغة الآلة.
  • تحتاج إلى مترجم (Compiler) لتحويلها إلى لغة الآلة.
  • أمثلة: FORTRAN, BASIC, Pascal, C, C++, Java, Python.
GROSSPAY = BASEPAY + OVERPAY;

المترجمات
3. المترجم والمفسر (Compiler vs. Interpreter)
المفسر (Interpreter)
  • يترجم البرنامج سطراً سطراً .
  • إذا حدث خطأ، يتوقف حتى يصحح المبرمج الخطأ.
  • أبطأ من المترجم، لكنه أسهل في التصحيح.
  • يستخدم مع: BASIC, Python, ...
المترجم (Compiler)
  • يترجم البرنامج مرة واحدة كاملة .
  • إذا حدثت أخطاء، تظهر بعد الترجمة مباشرة.
  • سريع جداً.
  • يستخدم مع: C, C++, Java, ...
خطوات إنشاء ملف تنفيذي (.exe) في C++
  1. إنشاء ملف المصدر (Source Code File) (.cpp)
  2. تجميع الملف باستخدام المترجم → ملف كائن (Object File) (.o)
  3. ربط الملف الكائن مع المكتبات المطلوبة باستخدام الرابط (Linker) → ملف تنفيذي (.exe)
Source (.cpp) → Compiler → Object (.o) → Linker → Executable (.exe)

لغة C++
4. ما هي لغة C++؟
  • C++ هي لغة برمجة شاملة (General-Purpose) و موجهة للكائنات (OOP) .
  • طوّرها بيارن ستروستروب (Bjarne Stroustrup) عام 1983 كامتداد للغة C.
  • تُعتبر لغة متوسطة المستوى – تجمع بين ميزات اللغات عالية ومنخفضة المستوى.
  • كان اسمها في البداية "C with Classes" ثم غُيّر إلى C++.
🔑 خصائص لغة C++
  • لغة حساسة لحالة الأحرف (Case Sensitive) – DATA ≠ Data ≠ data.
  • كل تعليمة تنتهي بـ ; (فاصلة منقوطة).
  • تحتوي على دالة main() حيث يبدأ تنفيذ الأوامر.
  • تستخدم مكتبات (Header Files) مثل #include <iostream> .
💡 لماذا ندرس C++؟
  • لغة مسيطرة في بيئات Unix و Windows.
  • تركيبها (Syntax) ألهم العديد من اللغات الشهيرة (Java, Python, Ruby).
  • قابلة للنقل (Portable) – تعمل على جميع الأجهزة.
  • قريبة من الآلة وتعطي إمكانيات غير محدودة.

المتغيرات
1. ما هي المتغيرات؟

المتغير (Variable) هو موقع تخزين مؤقت في الذاكرة الرئيسية (RAM) لتخزين البيانات.

  • يُستخدم لتخزين البيانات المدخلة من المستخدم أو نتائج العمليات داخل البرنامج.
  • يجب تحديد: نوع البيانات و الاسم (المعرف) .
أسباب استخدام المتغيرات
  • لتخزين البيانات التي يدخلها المستخدم.
  • لتخزين البيانات أثناء إجراء العمليات عليها.
مثال: حساب المتوسط بدون متغيرات
// mean1.cpp
// This program calculates the mean of three numbers.

#include <iostream>
using namespace std ;

int main ()
{
cout << "First Arithmetic Program \n\n" ;
cout << ( 12 + 5 + 10 ) / 3 ;
return 0 ;
} // end main

2. تعريف المتغيرات
ما هو تعريف المتغير؟
  • تعريف المتغير يُخبر المترجم بحجز مساحة في الذاكرة لحمل متغير من نوع معين واسم معين.
  • يجب تعريف المتغير قبل استخدامه لأول مرة.
  • صيغة التعريف: data_type variable_name;
خصائص المتغير
  • الاسم – لتمييز المتغيرات عن بعضها.
  • النوع – يحدد طريقة تخزين البيانات وحجمها في الذاكرة.
  • القيمة – البيانات المخزنة في المتغير.
  • الموقع في الذاكرة – عنوان في الذاكرة الرئيسية (RAM).
أمثلة على تعريف المتغيرات
// تعريف متغير واحد

int w1 , w2 , w3 , w4 ;

6. الثوابت (Constants)
ما هي الثوابت؟
  • الثوابت هي قيم لا تتغير طوال تنفيذ البرنامج.
  • تُستخدم لإعطاء أسماء ذات معنى لقيم ثابتة.

4. حلقة for
الصيغة العامة

break و continue
5. جمل break و continue
جملة break
  • تُنهي الحلقة فوراً .
  • ينتقل التنفيذ إلى أول جملة بعد الحلقة.
for ( int x = 1 ; x <= 10 ; x ++ )
{
if ( x == 5 )
break ; // توقف عند x = 5
cout << x << " " ;
}
// 1 2 3 4
جملة continue
  • تتخطى بقية الجمل في التكرار الحالي.
  • تنتقل إلى التكرار التالي .
for ( int x = 1 ; x <= 10 ; x ++ )
{
if ( x == 5 )
continue ; // يتخطى طباعة 5
cout << x << " " ;
}
// 1 2 3 4 6 7 8 9 10

الدوال
1. ما هي الدالة؟

الدالة (Function) هي كتلة برمجية صغيرة تؤدي مهمة محددة.

  • تُنفذ فقط عندما تُستدعى (called) .
  • هناك دوال مضمنة (مكتبية) مثل: pow() ، sqrt() ، ...
  • يمكن للمبرمج إنشاء دوال خاصة به (دوال معرفة من قبل المستخدم).
أهمية الدوال
2. لماذا نحتاج الدوال؟
  • تقسيم البرنامج إلى مهام صغيرة .
  • كتابة البرنامج وتصحيحه جزءاً جزءاً .
  • إمكانية عمل عدة مبرمجين على نفس البرنامج.
  • تجعل البرنامج أسهل للقراءة والاختبار والتصحيح .
  • تقلل حجم الكود (إعادة استخدام الكود).

  • نستخدم & قبل اسم المعامل.
void calculate ( int a , int b , int & sum , int & diff )

المتغيرات المحلية (Local Variables)
  • تُعرّف داخل دالة.
  • لا يمكن الوصول إليها من خارج الدالة.
  • تُحذف عند انتهاء الدالة.

  • تُعرّف خارج جميع الدوال.
  • يمكن الوصول إليها من أي دالة في البرنامج.
int num = 2 ; // متغير عالمي

  • إذا عُرف متغير محلي بنفس اسم متغير عالمي، يُخفي المتغير المحلي المتغير العالمي داخل الدالة.

9. الدوال العودية
الدوال العودية (Recursive Functions)
  • الدالة التي تستدعي نفسها .
  • تُستخدم للمشكلات التي تُعرف بدلالة نفسها.
// مثال: حساب المضروب (factorial)
int factorial ( int n )
{
if ( n <= 1 )
return 1 ;
else
return n * factorial ( n - 1 ) ;
}
factorial(5) = 5 × factorial(4)
factorial(4) = 4 × factorial(3)
factorial(3) = 3 × factorial(2)
factorial(2) = 2 × factorial(1)
factorial(1) = 1
→ factorial(5) = 5 × 4 × 3 × 2 × 1 = 120

المصفوفات والمؤشرات
3. المصفوفات والمؤشرات
العلاقة بين المصفوفات والمؤشرات
  • اسم المصفوفة بدون قوسين وفهرس يمثل عنوان البداية للمصفوفة.
  • اسم المصفوفة هو في الأساس مؤشر .
int list [ 6 ] = { 11 , 12 , 13 , 14 , 15 , 16 } ;
int * p = list ; // p يشير إلى أول عنصر في المصفوفة
الوصول إلى عناصر المصفوفة عبر المؤشر
// list[0] == *list == *p
// list[1] == *(list + 1) == *(p + 1)
// list[i] == *(list + i) == *(p + i) == p[i]
مثال
int list [ 6 ] = { 11 , 12 , 13 , 14 , 15 , 16 } ;
int * p = list ;

for ( int i = 0 ; i < 6 ; i ++ )
{
cout << "address: " << ( list + i ) << " " ;
cout << "value: " << * ( list + i ) << " " ;
cout << "value: " << list [ i ] << " " ;
cout << "value: " << * ( p + i ) << " " ;
cout << "value: " << p [ i ] << endl ;
}
⚠️ الفرق بين *list + 1 و *(list + 1)
  • *list + 1 → يضيف 1 إلى قيمة العنصر الأول. (list[0] + 1)
  • *(list + 1) → قيمة العنصر الثاني. (list[1])

تمرير المؤشرات للدوال
4. تمرير المؤشرات للدوال
تمرير المؤشر بالقيمة
  • يتم نسخ عنوان المؤشر.
  • التغيير على *p يؤثر على القيمة الأصلية.
  • التغيير على p نفسه لا يؤثر على المؤشر الأصلي.
تمرير المؤشر بالمرجع
  • يتم تمرير مرجع للمؤشر الأصلي.
  • التغيير على p نفسه يؤثر على المؤشر الأصلي.
مثال: دالة تأخذ مؤشرين
void f ( int * p1 , int * & p2 )
{
* p1 = 10 ; // OK: يغير القيمة المشار إليها
p1 = nullptr ; // فقط يغير النسخة المحلية
* p2 = 20 ; // OK: يغير القيمة المشار إليها
p2 = nullptr ; // OK: يغير المؤشر الأصلي
}

أربع نسخ من دالة swap
// 1. تمرير بالقيمة (لا يعمل)
void swap1 ( int n1 , int n2 )
{
int temp = n1 ;
n1 = n2 ;
n2 = temp ;
}

// 2. تمرير بالمرجع (يعمل)
void swap2 ( int & n1 , int & n2 )
{
int temp = n1 ;
n1 = n2 ;
n2 = temp ;
}

// 3. تمرير مؤشرات بالقيمة (يعمل)
void swap3 ( int * p1 , int * p2 )
{
int temp = * p1 ;
* p1 = * p2 ;
* p2 = temp ;
}

// 4. تمرير مؤشرات بالمرجع (يعمل)
void swap4 ( int * & p1 , int * & p2 )
{
int * temp = p1 ;
p1 = p2 ;
p2 = temp ;
}

الخلاصة
النقاط الأساسية
📍 المؤشرات تخزن عناوين الذاكرة بدلاً من القيم.
🔗 & → عنوان المتغير، * → قيمة العنوان المخزن.
📊 اسم المصفوفة هو مؤشر إلى العنصر الأول فيها.
📞 تمرير المؤشرات للدوال يسمح بتعديل القيم الأصلية.
🔄 swap3: مؤشرات بالقيمة، swap4: مؤشرات بالمرجع.
🔒 استخدم const مع المؤشرات لمنع التعديل غير المقصود.
💡 خلاصة سريعة
  • المؤشرات تسمح بالتعامل المباشر مع عناوين الذاكرة.
  • استخدم * للوصول إلى القيمة، و & للحصول على العنوان.
  • المصفوفات والمؤشرات مرتبطان ارتباطاً وثيقاً في C++.
  • تمرير المؤشرات للدوال يسمح بتعديل المتغيرات الأصلية.
  • احرص على تهيئة المؤشرات لتجنب الأعطال.
